# Resource owner inventory — D2

D2 is an internal authenticated native Orleans foundation operation for the future resource removal dependency chain. D1 supplies immutable creation identity. This contract supplies bounded resource-to-atomic-partition-to-physical-owner observation; it does not implement public SDK/MCP inventory, SQL/DROP, retirement, admission fencing or cleanup. The existing public functional scenario and all prior contracts remain unchanged.

This document freezes the native ABI selected in `contract.freeze-r2.original.json` (SHA256 `d8cfc9331b7681778c437d2d4a99d2449f948b6ef2962fa051dd3796abe5c8cc`). Its owning dependency inventory is [DROP TABLE foundation dependencies](../RelationalStorage/DropTableDependencies.md); [Resource lifetime creation identity](ResourceLifetime.md) remains the D1 authority. The ABI is selected; authoritative conservative may-contain policy is selected; Core producer/origin, readers, image and restore bodies are prepared together in this handoff. Canonical adoption, joined native coordinator/tests, semantic compilation and runtime qualification remain open.

## Error contract

- `Validation`: Malformed version/identity/page size/cursor shape before private data access.
- `Unauthenticated`: Existing peer/principal authentication refusal.
- `PermissionDenied`: Fresh persisted principal is not permitted administrator.
- `NotFound`: Complete absence of source definition+D1 at initial authority capture only.
- `Corruption`: Malformed definition/lifetime pair, index row/origin/header or contradictory topology metadata.
- `RecoveryRequired`: Missing/unproven writer/enrollment/import origin, unsettled ownership/restore closure, unknown required owner configuration; never empty-success.
- `TokenInvalidated`: Source incarnation/definition/policy/read-generation/cursor identity changed relative captured witness.
- `OwnershipLost`: Physical owner, registered directory or placement revision/movement witness changed during operation.
- `RevisionConflict`: Enrollment revision changed during paged capture or final validation.
- `BudgetExceeded`: Actual examined/read/output/native capacity exhausted, never truncated Complete.
- `CursorExpired`: Original expiry reached before completion; no renewed deadline.
- `Cancellation`: Original cancellation propagates/joins existing native operation; no invented successful outcome.
- `Transport`: Original native owner-unavailable/transport failures propagate through existing failure boundary, never skipped group or empty page.

Only initial complete absence of the source definition and D1 yields NotFound. A missing half or malformed pair is Corruption. Missing/unproven writer/import origin or unknown required owner configuration is RecoveryRequired. Unknown or unreachable owners are never silently omitted. Subsequent source identity/cursor changes invalidate the captured witness; owner/directory/placement changes retain OwnershipLost; enrollment revision changes retain RevisionConflict. Transport failures propagate through existing native boundaries without fabricating a page.
