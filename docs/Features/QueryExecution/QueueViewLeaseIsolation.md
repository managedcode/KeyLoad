## Required observable contract

Actual producer operations atomically append two literal events and enqueue two literal messages with payload and header read/use policies. A separate authorized worker genuinely receives the first message. One persisted reader has Query and QueueInspect, without protected field grants. Native SQL, typed AST and the actual SQL operation compiler, plus SDK and official MCP SQL/AST/Q1 routes over Aspire-owned Docker RF3, must return the same ordered independent row values and metadata.

Each star row contains exactly id, state, attempts, stateVersion, notBefore, expiresAt, payload and headers. It retains the original two omitted source policy paths in their declared order. Explicit selection of the unsupported leaseOwner, leaseVersion, leaseUntil, token and deliveryGeneration fields returns five nulls without delivery authority. These unprotected unknown paths have Redacted=false and empty RedactedFields under the required KL-064 source-selective metadata correction; this flow must not freeze the earlier all-omitted-path defect. Explain has one independently checked static safe row, no cursor, a real positive public cut and the actual published scan budget.

Every read is bracketed by complete state comparison. The native lane conserves the entire original canonical row image, physical position, all nine store identity fields and exact original journal last/committed/term cuts. The public lane conserves full message inspections, literal complete source event identities/ordinals/data, original observed recorded timestamps, exhausted source page and outbox status. Public cut numbers are independently required positive and snapshot-consistent, then normalized only for cross-call comparison because distinct requests can run on different RF3 node owners. Public observation does not infer raw byte or private result authority.

The same reader clients lose only QueueInspect at policy epoch2, while Query remains; all model-read routes refuse current permission. Epoch3 repairs it and the original clients immediately read correctly. This principal is distinct from the unchanged worker, so worker receipt history is not accidentally fenced by the reader policy change. Protected field-use predicates refuse, model cursors are explicitly unsupported, stale event generation2 refuses TokenInvalidated, and a syntactically valid generic T-SQL UPDATE remains unsupported. The actual TUnit caller token governs every ordinary native query/compiler read and explicit warm/cold phase boundary, while joined conservation still runs after failures. Pre-cancelled native queries throw OperationCanceledException; typed SDK reads return Cancelled with no value and official MCP preserves caller cancellation. No claim is made about mid-scan interruption or the separate Q1 mutation classifier.

Original receive IDs still return the complete original delivery while the lease remains current. Renew uses the original opaque token, changes only the real deadline and stateVersion2→3, and keeps leaseVersion, attempt, generation, payload, headers and sibling unchanged. The original token then ACKs version4, removes the body and keeps the sibling Ready. A fresh third producer remains readable. Current release of the original consumed Receive correctly refuses StaleLease.

The native lane separately retains the very first genuine raw outcome and scoped locator bytes for each resource/principal configuration, mixed producer, Receive, Renew, ACK and healthy producer. It compares original complete results including private composition references and exact retained signed operation fields/native payloads. Trusted already-applied original-index replay returns original stored success, while current submission and ResolveOutcome reauthorize and validate consumed leases.
