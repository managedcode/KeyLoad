# QueryExecution

QueryExecution owns the authorized, bounded query surface of the database: typed AST queries, T-SQL lowered to the same operations, SQL views over events, queues and topics, typed joins, declarative model composition and distributed multi-partition queries. Every request runs on the caller's connection grain ([ADR-125](../ADR/ADR-125-connection-owned-execution.md)), reloads persisted authorization and shares one cancellation, deadline and read budget. Distributed queries are ordinary Orleans grain calls to the logical partitions whose silo-local ZoneTree owners answer, merged by the connection grain ([DistributedQueryExecution](QueryExecution/DistributedQueryExecution.md), [ADR-136](../ADR/ADR-136-orleans-partition-ownership.md)).

T-SQL syntax comes from Microsoft ScriptDOM: [requirements](QueryExecution/ScriptDom.md), [ADR-130](../ADR/ADR-130-microsoft-scriptdom-tsql.md) and the [conformance inventory](../implementation/sql-client-conformance.json). Grammar acceptance, executable semantics and wire protocol are separate gates; no complete-SQL, TDS or production qualification is claimed.

```mermaid
flowchart LR
    Request[Bound SQL or AST request] --> Cut[Authorized consistent storage cut]
    Cut --> Source[Budgeted point index or full scan]
    Source --> Prepared[One parse and prepared scalar order keys]
    Prepared --> Selection[Bounded page prefix selection]
    Selection --> Page[Exact ordered projected page and signed cursor]
    Page --> Limit[Complete protocol byte limit]
```

## Query core contract

`QueryPage.CutPosition` identifies the physical committed read cut. A cursor
retains its original cut while its existing ownership, source and authorization
fences remain valid. This position is distinct from the canonical command
sequence in `CommitToken.Position`: group commit can persist several commands in
one journal frame, and local derived commits can advance the physical position.
The two counters must not be compared as though they share one unit.

Complete range traversal stops its internal visitor at the provider's record ceiling before a lookahead can exceed that physical page's work budget. It resumes after the last delivered storage key inside the same owning gate. An internal page boundary does not become the caller's terminal stop; an explicit caller stop remains terminal even at that boundary. A contiguous range of deleted documents can therefore span storage pages while the query continues collecting its requested live rows. Physical examined-record, byte, read-cut and cancellation checks remain enforced by their existing owners.

Q1 provides typed adapter validation, authorization, deterministic scalar order, a bounded current-cut query and cursor, and a capability manifest. A global serializable snapshot, arbitrary joins and user delegates, and cross-shard execution are not declared implemented. [Search](Search.md) and [ChangeFeeds](ChangeFeeds.md) have their own behavior contracts; a live scalar query uses the same safe query boundary.

Decisions: [ADR-147 id continuation](../ADR/ADR-147-id-ordered-query-continuation.md), [ADR-149 no operation limits](../ADR/ADR-149-no-operation-limits.md), [ADR-004](../ADR/ADR-004-committed-read-views.md), [ADR-010](../ADR/ADR-010-query-budgets-security.md), [ADR-013 AST](../ADR/ADR-013-authorized-query-ast.md), [ADR-020 contexts](../ADR/ADR-020-independent-query-contexts.md), [ADR-022 policy epoch](../ADR/ADR-022-policy-epoch-revocation.md). ## SQL as the central language

SQL exists because KeyLoad is one composable database for AI agents: documents,
typed tables, graphs, blobs, queues, events, vectors/search and time series can
reference and use one another. [DatabaseComposition](DatabaseComposition.md) /
[ADR-067](../ADR/ADR-067-composable-agent-database.md) specify queue -> linked
entities -> knowledge graph and graph -> queued actions in one authorized bounded
request. The first server-derived stage uses composing mutations through existing
canonical SQL CALL; full declarative model sources/JOIN/DML remain required under
ADR-065. One shared language must not stop at independent calls per model.

Full SQL syntax and a client connection protocol are required. [ADR-065](../ADR/ADR-065-full-sql-client-compatibility.md) owns
the ordered implementation contract; [conformance inventory](../implementation/sql-client-conformance.json)

Q1/SELECT/CALL is a stage; full SQL and protocol remain pending.
